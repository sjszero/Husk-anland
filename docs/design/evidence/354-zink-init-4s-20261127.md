# 354 · 每个 GL 进程启动固定付 4.2 s：定位到 zink 上下文初始化

日期：2026-11-27（CST）
设备：RMX3357 / MT6893 / Mali-G77 MC9 / Android 13 / 4.19.191 / 4 KiB 页
宿主：`com.linuxhub.myth.husk`（黑盒）

## 0 · 结论

| 测法 | 耗时 | 判定 |
|---|---:|---|
| `glxinfo -B`（默认 zink→PanVK） | **4275 ms** | FACT |
| 同上，第二次 | 4275 ms | FACT（不是一次性缓存） |
| `HUSK_GPU=llvmpipe glxinfo -B` | **357 ms** | FACT |
| `eglinfo -B` | 4287 ms | FACT |
| `xset q` / `xdpyinfo`（纯 X 往返） | 27 / 28 ms | FACT |

**每个走 GL 的进程，初始化要固定付约 4.2 s；换 llvmpipe 只要 0.36 s。**
这和第 353 号证据里“首帧前 4.1 s CPU 0% 的空窗”量级、位置都对得上。

## 1 · 排除项（都不改变这 4.2 s）

| 变量 | 结果 |
|---|---|
| `MESA_SHADER_CACHE_DISABLE=1` | 4271 ms |
| `vblank_mode=0` | 4271 ms |
| `ZINK_DEBUG=noreorder` | 4276 ms |
| `LP_NUM_THREADS=1` | 4280 ms |
| `LIBGL_ALWAYS_SOFTWARE=1` | 4321 ms（该变量在这条路径上不生效，不能当对照） |
| `VK_ICD_FILENAMES=…/lvp_icd.json` | 4377 ms（被 `etc/husk/gpu-env` 的坏值纠正覆盖，不能当对照） |

所以：不是着色器缓存、不是 vsync、不是线程池、不是 X 往返、不是会话总线
（`dbus-send ListNames` 25–28 ms）。

## 2 · 与冷启动的时间线对齐

```text
+4.81s  gnome-shell 创建
+4.9 ~ +9.0s  utime/stime 增量恒为 0，wchan=do_sys_poll / futex_wait
+9.0s 起  满核 3.4 s
+14.7s 首帧
```

一段 4.2 s 的“等”正好嵌在 shell 起来之后。mutter 初始化要建 GL 上下文，
和 `glxinfo` 走的是同一条 zink 初始化，量级一致。

## 3 · 最可能的内部原因（INFERENCE，未证实）

每次 GL 启动都打印：

```text
MESA: warning: kbase: KBASE_IOCTL_MEM_EXEC_INIT failed: Operation not permitted
       (executable BO allocation will not work)
```

PanVK 想为着色器代码申请可执行 BO，被内核（Android 侧 SELinux/权限）拒绝，
随后走回退路径。4.2 s 很可能花在这个“失败→重试→回退”上。
设备上 `dmesg` 对 shell 用户不可读（输出为空），无法用内核日志确认；
要证实需要在有 root 的机器上看 kbase 的 ioctl 日志，或对 PanVK 打点。

## 4 · 对“整体慢 1~2 倍”的解释

- 文件路径密集负载：我们比 PRoot 快 2.83×（stat）、5.85×（open+close）。
- 但每开一个 GUI 程序先付 4.2 s，`glxgears`/`glxinfo`/`eglinfo` 全部如此。
- 冷启动桌面 14.7 s 里，4.2 s 就是这一项。
- 所以“参数快、用起来慢”不是矛盾：**快在 syscall，慢在 GL 初始化**，两件事互不相干。

## 5 · 可动的方向（按代价排序）

1. 让 PanVK 不再走 exec-BO 的失败回退（需要内核/SELinux 侧允许，或换一种分配方式）。
2. 桌面范围内延迟建 GL（能省首帧时间，但省不掉第一个 GL 程序的开销）。
3. 明确标注为已知边界：llvmpipe 0.36 s 但无硬件加速，不适合当默认。

## 6 · 未验证

- 4.2 s 是否确实由 `KBASE_IOCTL_MEM_EXEC_INIT` 的 EPERM 回退造成（无 root/内核日志）。
- PRoot 同机同指标（`glxinfo -B`）的对照数字，本轮未取。
