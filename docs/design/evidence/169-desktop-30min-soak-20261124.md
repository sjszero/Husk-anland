## 3 · 这一维能说明什么、不能说明什么

**能**：空闲桌面上没有 fd 泄漏、没有线程泄漏、没有僵尸、没有持续的内存增长——这是"能不能
挂着不炸"的最小证据；30 分钟里进程没有重启。

**不能**：

- 不是内存泄漏的证明：只覆盖**空闲**桌面，没有窗口频繁开关、没有长跑的 GPU 负载、
  没有反复启动应用（那些会走另一条分配路径）。长时间（小时级）与负载型 soak **未测**。
- 没有测「睡眠/唤醒」：设备是否设了锁屏凭证未知（`locksettings get-disabled` = false），
  远程把屏幕关掉有可能回不到已解锁状态，所以**没做**，标 **未测（UNKNOWN）**，不拿"应用还在"
  当"睡眠后恢复"的证据。
- GPU 侧计数器（提交/完成帧数）这一轮没有接进采样，所以"仍然在画"来自像素检查，不来自帧计数。
