- 关屏 150 秒不会杀掉这个会话：没有被低内存杀、没有重启、合成器还在按状态出帧。

## 不能说明什么（重要）

- **不是深睡/Doze**：设备一直 USB 供电、adb 在线，SoC 没有进能真正冻结进程的深度睡眠。
  几小时级别的息屏、`cmd deviceidle force-idle` 那种 doze、以及电池供电下的表现都**未测**。
- fd 41 → 40 的这一个我没有归因（可能是某个瞬时的 socket/eventfd 在关屏时被关掉）。
  只记事实，不当成"泄漏"也不当成"已修"。
- 唤醒后没有做输入注入验证（触摸/键盘在唤醒后是否立刻可用**未测**）。
- 锁屏：这台机器的 `locksettings get-disabled` 是 `false`，所以唤醒后理论上可能出现锁屏界面；
  本次唤醒后没有出现挡住我们读取的现象，但**没有**测"有凭证的锁屏 + 解锁后桌面是否完好"。
