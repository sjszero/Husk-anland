`root/inp-left.log` 与 `root/inp-right.log`。

## 4 · 滑动为什么只能记 UNKNOWN

同一探针再开 25 秒，执行两次：

```text
adb shell input swipe 500 600 1500 600 500
adb shell input swipe 1500 600 800 600 500
```

结果：

```text
# window requested x=0 w=2400, actual root x=0 y=0
# total=0
```

这只能证明「经 `adb shell input swipe` 到 XI2 的这条路径没有出现 Motion 序列」。可能是测试注入器
把 swipe 当成另一类手势，也可能是 2.0 输入桥没有产出拖动事件；本轮没有拆开这两层，因此结论是
**UNKNOWN / 未验证**，而不是已实现。点击路径已有上面的直接证据。

同样，`adb shell input mouse` 的注入只稳定产生 Motion，没有稳定按键；它是测试注入器行为，
不能拿它单独判 Husk 失败。
