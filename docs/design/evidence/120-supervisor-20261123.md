## 3. 过程中修掉的两个真 bug（都留了注释）

1. **argv 指针指错位置**：程序路径是"rootfs 前缀 + guest 路径"拼出来的一整串，但指针
   落在了前缀之后，于是 ld.so 去开宿主 `/usr/bin/bash` →
   `cannot open shared object file`。现在 `prog_at` 在拼之前就记下来。
2. **子进程继承了被阻塞的 SIGTERM**：监督器为了 signalfd 阻塞了 TERM/INT/QUIT，
   这个掩码跟着 exec 进了服务，于是停机时 `kill -TERM` 无效，只能等满 5s 再 SIGKILL。
   现在子进程序 exec 前 `SIG_SETMASK` 清空。停机耗时从 5s 降到 0.5s。

另外把子进程的 `PATH`/`HOME` 换成容器值：否则 guest 里的 `sleep` 都找不到（Android PATH）。
