# 262 · 最终 symlink 并发替换：宿主哨兵未被改动

日期：2026-11-26（CST）。设备：RMX3357 / MT6893 / Mali-G77 / Android 13 / kernel 4.19.191 / 4 KiB。
被测物：`tools/loader/ld-embedded.so`（SHA-256
`f21663f1d9699faf1e18fbc2d90bc5bd68cf5fbfb5e496d765437f47aeab841e`），通过
`run-guest.sh` 进入 App 的真实 guest 根。

## 0 · 结论

FACT：在 4 个并发 worker、共 212,050 次 `chmod` / `utimensat` / `chown` / `open` /
`lstat` 操作期间，最终 symlink 被原子替换 12,860 次。宿主侧哨兵文件在测试前后的内容
SHA-256、权限 `640` 和 mtime `1577811660` 完全一致。

FACT：探针从 guest 内直接 `lstat` 宿主绝对路径时得到 `ENOENT(2)`，证明该路径没有作为
guest 的正常可达文件暴露。之后它只被写入 symlink 的 target 字段，用来测试并发替换。

## 1 · 探针方法

`tools/probe/path-race-probe.c`：

- 在 guest `/tmp/husk-path-race` 创建 `guest-victim`。
- Toggler 线程反复创建两个临时 symlink，并通过 `rename()` 原子替换最终名字
  `race-link`；目标交替为相对 guest 文件和宿主 App 私有绝对路径。
- 4 个 worker 线程并发调用 `chmod`、`utimensat`、`chown(uid=-1,gid=-1)`、
  `open(O_TRUNC)` 和 `lstat`。
- `NR_FAKE_ROOT=0`，让 `chown` 走真实 `fchownat` 路径，而不是只更新虚构所有权表。
- 宿主脚本在 App 私有目录创建哨兵，记录运行前后的内容、mode 和 mtime。

入口：`tools/device-tests/run-path-race-probe.sh`，已接入 `make gate-a`。
