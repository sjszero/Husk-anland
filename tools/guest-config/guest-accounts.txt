# Accounts the Ubuntu rootfs is missing but its own service configuration
# expects. A container image ships these; ours does not, so the deploy step adds
# them. Without them `dbus-daemon --system` refuses to start with
# "Could not get UID and GID for username messagebus".
#
# name:uid:gid:group_also
messagebus:102:102:1
pulse:103:103:1
whoopsie:104:104:1
geoclue:105:105:1
netdev::111:0
# rtkit and pipewire are added here for the same reason: their postinsts create
# the accounts with adduser/groupadd, and shadow's lock protocol needs a hard
# link (nlink==2) which this SELinux domain refuses. Shipping the accounts in
# the image, the way a distro image does, keeps dpkg --configure working.
rtkit:106:106:1
pipewire::107:1
# polkitd 需要自己的系统账号；没有它时，iio-sensor-proxy 的 Claim* 调用会在
# polkit 的 subject/name 解析阶段失败。这个 uid/gid 只在本 guest 里有意义。
polkitd:101:101:1
